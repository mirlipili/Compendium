# Compendium pour Android

Une application Android pour un accès hors ligne au Vetcompendium.

## À Propos du Projet

Compendium est une application mobile conçue pour les professionnels et étudiants vétérinaires. Elle offre un moyen simple et efficace de parcourir et de rechercher dans la base de données Vetcompendium sans nécessiter de connexion Internet active, ce qui en fait un outil fiable pour une utilisation en déplacement.

## Fonctionnalités

* **Accès Hors Ligne :** Toutes les données sont stockées sur l'appareil pour un accès à tout moment, n'importe où.
* **Fonction de Recherche :** Trouvez rapidement les informations dont vous avez besoin.
* **Interface Conviviale :** Une mise en page claire et intuitive pour une navigation facile.

## Stack Technique

* **Langage :** [Kotlin](https://kotlinlang.org/)
* **Plateforme :** Android
